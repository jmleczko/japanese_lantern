# Japanese Lantern Build

Static site (plain HTML, no build step) for the ATtiny85 lantern project.

- `index.html` — home page linking to the three documents
- `build.html` — 7-step cumulative build plan
- `schematic.html` — full schematic, pin reference, component notes
- `parts.html` — parts checklist

## Deploy

Hostinger's Git integration deploys the `main` branch to `public_html` (or a subfolder).
Pushing to `main` redeploys automatically when Auto-deployment is on.
